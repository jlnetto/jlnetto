# Icons

`scripts/build.mjs` downloads each logo once and keeps it here, so later builds work offline.

- [Simple Icons](https://simpleicons.org) 16.33.0, CC0 1.0 (`simple-icons-*.svg`)
- [Devicon](https://devicon.dev) 2.17.0, MIT (`devicon-*.svg`)
- [LobeHub Icons](https://github.com/lobehub/lobe-icons) 1.95.1, MIT (`lobehub-*.svg`)

Each logo is a trademark of its owner and appears here only to name the tool.
